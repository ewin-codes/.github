## EWIN.codes

We build software for businesses that run on Odoo: custom modules, integrations
with outside services, implementation and support.

### Open source

**[EWIN Inbox](https://github.com/ewin-codes/ewin-inbox)** is an omnichannel
customer inbox for Odoo 18. Telegram, WhatsApp, Email, Instagram, Messenger,
Viber and Live Chat land in one Odoo-native interface, linked to contacts and
CRM leads, with operator assignment, scheduled replies, canned replies and
reporting. LGPL-3.

[![EWIN Inbox](https://raw.githubusercontent.com/ewin-codes/ewin-inbox/18.0/screenshots/conversation.png)](https://github.com/ewin-codes/ewin-inbox)
